# Java Low-Level Design Interview Preparation

A collection of Java projects for practicing object-oriented design,
low-level design (LLD), design patterns, and interview-ready implementations.

## Projects

### 1. Parking Lot
A parking lot system design demonstrating object-oriented modeling
and parking spot allocation.

### 2. Rate Limiter
A rate limiter implementation exploring request throttling and the
Token Bucket algorithm.

### 3. Splitwise MVP
An expense-sharing application covering users, groups, expenses,
splitting strategies, balances, settlements, and debt simplification.

## Technology

- Java
- Maven
- JUnit 5
- Object-oriented design and SOLID principles
- Design patterns

## Repository Structure

- `Parkinglot/`
- `rate-limiter/`
- `design-splitwise-mvp/`

Each project is maintained in its own directory with its implementation
and project-specific documentation.

## Purpose

The goal is to build working, testable implementations of common
LLD interview problems and document the design decisions behind them.
